# BMI MEASUREMENT   
It is a BMI measurement webapp, where user enter height and weight and it measure their Body Mass Index. using BMI formula : weight / height*height.

[**Live Demo**](https://bmi-measurement-ten.vercel.app/)

## Tech Stack
*   **Frontend:** HTML5, CSS3
