# BMI MEASUREMENT   
It is a BMI measurement webapp, where user enter height and weight and it measure their Body Mass Index. using BMI formula : weight / height*height. Responsive Design work in Phone also. 

[**Live Demo**](https://bmi-measurement-ten.vercel.app/) 
---
# Rules/Formula : 
- Enter Weight
- Enter Height
- Calculate BMI using Weight / Height^2 formula. 
## Tech Stack
*   **Frontend:** HTML5, CSS3 
*   **Logic:**  JavaScript
